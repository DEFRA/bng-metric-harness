# BNG scenarios

Paired baseline / post-intervention GeoPackages from the bng-library
scenario catalogue, generated by `npm run generate:scenarios`. Each row
names the feature a tester should open to exercise the scenario.

Seed **1** · 37 scenario(s) across 8 purpose(s).

Each scenario also has a metric workbook, written into `The_Statutory_Metric_Macro_Disabled_1.0.4.xlsx` and recalculated. Its figures are the metric's own, from Defra's formulas, except that the metric's known bugs are corrected: `corrections` in `manifest.json` lists each one. *Warnings* counts distinct warnings the metric shows on feature rows; *Rejected inputs* counts values the workbook's own drop-down lists do not offer.
