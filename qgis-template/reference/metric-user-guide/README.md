# The Statutory Biodiversity Metric – User Guide (June 2026)

A word-for-word Markdown copy of Defra's user guide, one file per chapter, so
that a reader opens only the chapter it needs. © Crown copyright 2026, used
under the Open Government Licence v3.0. The licence text is in
`00-front-matter.md`. Figures and screenshots are `[Figure: …]` placeholders.
Page numbers and table headers that repeat on a new page are left out.

**The service assumes every local planning authority has published its LNRS.**
It follows the guide's "LNRS has been published" rules (Table 7 in
`04-habitat-quality-inputs.md`): baseline strategic significance is always
Low, and a post-intervention habitat is Low or High. Medium is not used. A
marked *BNG Service note* in chapter 4 says so. It is the only text added to
the guide.

To find a topic, search this folder for a phrase, then open the one file.
