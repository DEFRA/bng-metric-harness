about=Moves a habitat map out of the BNG Service QGIS template without anyone needing a command line.
    Convert to legacy splits a BNG Service GeoPackage into the baseline and post-intervention pair the older Biodiversity Metric service expects, and can also write the three CSVs the Excel GIS import tool reads.
    Convert from legacy joins a legacy baseline and post-intervention pair back into a single BNG Service GeoPackage, rebuilding as much baseline-to-post-intervention lineage as the legacy files allow and reporting exactly what had to be inferred.
    Export to the Statutory Metric fills a copy of the metric workbook directly, with no CSVs and no import tool in between.
    All three appear in the Processing Toolbox and under Plugins > BNG Template Convert. No dependencies beyond QGIS itself.

changelog=1.2.0
    Conditions and retention categories now reach the Statutory Metric and the import tool CSVs without the list number in front of them, so habitat and watercourse rows score instead of reporting Check Data. Watercourse rows also reach the retained, enhanced and enhancement columns for the first time.
    Filling the metric is about ten times faster, shows how far along it is, and no longer holds up the rest of QGIS while it runs.
    Converting back from legacy separates features whose recorded parent is missing from features that are simply new, rather than warning about both.
  1.1.0
    Export to the Statutory Metric, and multi-workbook output for a site too large for one.
